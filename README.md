# TOP 10 Multiplayer — 4–12 Players

## Run locally
1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.
6. Create a room, choose 4–12 players, round time, and prize pool.
7. Share the Room Code with the other players.

## Included in this version
- 4–12 player rooms
- Round timer resets every round
- Host-selected prize pool, shown only on the final screen
- Top 3 prize split: 50% / 30% / 20%
- Dark, professional Steam-inspired glass UI
- Smooth drag/drop and screen animations
- Answer imagery with Wikipedia thumbnails and automatic fallback avatars
- Sound effects and tension audio near the end of a round
- Fullscreen mode
- Streamer Mode that hides the Room Code (player names remain visible)
- Connection/reconnection handling
- Reveal, round results, final podium, awards-ready visual structure

## Multiplayer over the Internet
For players on different networks, deploy this Node.js app to a public host. Socket.IO connects automatically to the server.
